# Farhat Game: Project Document (Architecture, Tech Stack, Delivery)

Dated 3 November 2026.

This project builds a single-player, story-driven 3D action-adventure of 52 chapters, adapted from the Farhat animated series, on a data-driven Unity (C#) architecture. It is feasible only as a staged release: a three-chapter vertical slice first, then Part One (26 chapters) in episodic drops, then Part Two. This document is the engineering and delivery companion to the Game Script and Design Bible, which holds the story, characters and chapter design.
